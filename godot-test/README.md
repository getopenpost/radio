# Endless fox, 3D: the M1 Godot test

Built 31 October 2026 as a test beside the live stream. Nothing in `src/` or
the deployment is touched; this directory is uncommitted and self-contained.
It answers the M1 milestone: the fox walking right through the palette+dither
pipeline for a full day cycle, compared against the approved boards.

## Look at it

1. **`output/m1-preview.mp4`** first: 60 seconds, one full day (morning, day,
   golden dusk, night with stars and lit windows, golden dawn), 1280x720
   (2x nearest from the 640x360 grid), music muxed from a library track.
2. Or run it live: open `project.godot` with the bundled `bin/Godot.app`
   (Godot 4.7.2, already downloaded) and press Play. The window is fixed at
   1280x720; keep it unresized for correct pixels.
3. Stills across the day are in `output/frames/` (1800 PNGs, one per frame
   at 30 fps).

## Re-render

```
cd godot-test
./bin/Godot.app/Contents/MacOS/Godot --path . -- --frames-dir=output/frames --max-frames=1800
../.devenv/profile/bin/ffmpeg -y -framerate 30 -start_number 2 \
  -i output/frames/frame_%05d.png -i ../library/tracks/broken-355597.flac \
  -t 60 -c:v libx264 -crf 16 -pix_fmt yuv420p -c:a aac -b:a 160k \
  -shortest -movflags +faststart output/m1-preview.mp4
```

The frames mode runs on a fixed 1/30 s clock (palette, scroll, fox animation
all advance manually), so renders are deterministic regardless of real
display rate.

## How it works

- `scripts/palette.gd`: the landscape subset of `src/stream/scene/palette.js`
  (38 slots), generated by `tools/gen_palette.py` with the same OKLCH
  conversion. Day, night and sparse golden-hour tables blend per frame.
- `scripts/backdrop.gd`: the 2D sky in exact slot colors: clouds, sun disc,
  moon, stars, two tileable parallax mountain ridges scrolling at fractions
  of the ground speed. No lighting touches these, so the palette's depth
  order holds by construction.
- `scripts/main.gd`: the 3D band in a transparent-sky SubViewport (ortho side
  camera, path line at 84% of frame height, fox at 1/5 of frame height, fox
  auto-rotated to face right via its rig's Neck1/Tail1 bones). The fox's GLB
  materials are restyled to palette slots (Main->fur, Main_Light->cream, ...)
  so lit fur quantizes onto the intended tones; houses' native 'Windows'
  material becomes the glowing window slot; trees are built in code from
  palette-exact canopy and trunk primitives. The strip repeats a fixed
  24-slot pattern (spacing 3.6 m) and recycles instances, so it never ends.
- `shaders/quantize.gdshader`: the style pass, run LAST in the window. It
  finds each pixel's two nearest palette slots and ordered-dithers between
  them with a world-anchored 4x4 Bayer matrix (the x index shifts with
  scrolled distance), so flat slot areas stay solid and only transitions
  band, matching the 2D scene's dither rule.

## Two engine findings worth remembering

1. **Movie Maker's PNG writer shifts dark values.** `--write-movie` captures
   the linear window buffer and its own conversion drifts dark slots by a
   level, spraying near-palette noise across dusk and night frames (verified:
   window content was pure palette, the movie PNGs were not). This test
   captures the window image directly from GDScript instead, on a fixed
   clock, and every frame verifies as pure palette (26-33 unique colors,
   exact 2x pixel doubling). The production render path must keep this or
   post-snap frames during encode.
2. **Viewport textures take a lossy round trip.** Compositing viewports into
   other viewports resamples through float/half-float textures and
   re-introduces drift. The quantizer therefore runs in the window itself,
   after every other draw, which also absorbs any upstream drift.

## Known gaps, by design (decide in the morning)

- **Global nearest-slot matching, not per-material slot pairs.** The fox's
  lit body dithers across its whole fill, and dawn/dusk transitions show
  blotchy patches where lerped slots pass close to each other. The
  production plan's per-material slot shader is the real fix.
- **The shipped Walk clip is an in-place cycle** (3 cm paw sweep, zero root
  motion). Playback is slowed (0.55x) against a 0.75 m/s scroll so it reads
  acceptably, but true no-slide needs the distance-driven clips from
  `../output/godot-3d-pipeline-2026-10-30/research/animation.md`.
- Night fox contrast is low against dark houses (palette-driven; the
  reference keeps night readable through warm lights, which only the
  windows provide here).
- The CC0 bicycle reads thin; boats, broom and the calisthenics park are M2
  scope, as are seasons (this test runs one neutral season) and weather.
- Vision QA notes carried into tuning: sun raised above the tree line, moon
  gated to deep night, alternate houses mirrored to avoid the copy-paste
  duplex look, ambient raised to soften the fox's lighting gradient.
